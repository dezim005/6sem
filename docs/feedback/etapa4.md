## 🛠️ DIRETRIZES DE AVALIAÇÃO MOBILE

1. **Uso de Recursos Nativos**: Analisa se o projeto faz uso de hardware local do smartphone (GPS, Sensores, Câmera, Notificações Push ou cache AsyncStorage).
2. **Resiliência de Rede**: Valida a amarração de conexão dinâmica do app com endpoints distribuídos e o tratamento lógico offline-first.
3. **Mapeamento de Testes e Simulações**: Checa as suítes de testes automatizados móveis e as evidências instrumentadas de emulação bem-sucedida relatadas.
