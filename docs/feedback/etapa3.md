## 🛠| DIRETRIZES DE AVALIAÇÃO WEB

1. **Validação de Ingestão de API**: O avaliador checa se o front de fato consome e injeta dinamicamente dados do backend, analisando imports centrais (Axios/Fetch).
2. **Conformidade Responsiva**: Verifica as regras e tags CSS para atestar se a renderização em diferentes resoluções funciona corretamente e atende o design dos mockups.
3. **Mapeamento de Testes e Deploy**: Checa se existem scripts funcionais de auditorias web (Lighthouse) e suítes de testes unitários ou ponta a ponta executáveis.
