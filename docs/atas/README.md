# 📅 Acompanhamento Individual e Portais de Feedback

Esta pasta centraliza as páginas individuais de acompanhamento e evolução de competências de cada membro do grupo.

## 🚀 Como funciona o Acompanhamento?

Os estudantes **não devem assinalar manualmente as ATAs/Fichas de Acompanhamento**. Toda essa atividade é administrada e atualizada de forma externa e centralizada pela coordenação e corpo docente da disciplina.

A dinâmica de monitoramento e feedback continuado opera da seguinte maneira:

1. **Configuração da Equipe**: A equipe preenche os nomes e os usernames corretos do GitHub no arquivo mestre [STUDENTS.md](../../STUDENTS.md) na raiz do repositório.
2. **Auditoria de Contribuição**: A coordenação do curso analisa o cadastro em [STUDENTS.md](../../STUDENTS.md) e verifica quais trechos de documentação e código foram de fato desenvolvidos por cada membro.
3. **Escrita do Feedback e Atividades**: O grupo de professores preencherá diretamente os arquivos nesta pasta (`aluno1.md` a `aluno6.md`), alimentando o **Painel Consolidado de Notas de Rubricas** e inserindo na tabela de atividades individuais qual foi a **Contribuição Real Detectada** do aluno para cada rubrica e seu respectivo **Parecer Pedagógico/Técnico**.
